# 단권화

흩어진 시험 자료를 한 권으로 묶는 웹앱. 강의 필기·교재 발췌를 붙여넣거나 PDF·사진으로
올리면 단원별 정리본을 만들고, 그 정리본 내용으로 문제를 내고 채점해서 약한 단원을 모아준다.

빌드 도구 없는 순수 HTML 한 파일이다. 프레임워크도, 번들러도, 의존성 설치도 없다.

## 하는 일

- **정리** — 자료를 넣으면 단원으로 나누고, 본문·비교표·"시험에 나오는 지점"을 만든다
- **출제** — 정리본 내용만으로 풀 수 있는 객관식·OX·단답 문제를 만든다
- **두 가지 풀이 모드**
  - 연습 — 한 문제씩 즉시 채점, 그 자리에서 풀이와 정리본 근거를 보여준다
  - 실전 — 타이머와 OMR 답안지, 전부 푼 뒤 제출하면 채점표가 나온다
- **약한 단원** — 푼 기록을 단원별로 모아 정답률이 낮은 순으로 보여준다
- **여러 과목** — 과목을 몇 개든 만들고 자료를 계속 덧붙일 수 있다
- 라이트/다크, 모바일 레이아웃

## 두 가지로 돌아간다

같은 코드가 실행 위치를 알아서 판단한다.

| | Claude 안 (`artifact.html`) | 웹 (`index.html`) |
|---|---|---|
| AI | 여는 사람의 Claude 계정 | 여는 사람의 Anthropic API 키 |
| 저장 | 서버 — 기기가 바뀌어도 유지 | 그 브라우저에만 |
| 공유 | 링크를 받은 사람이 자료·정리본·문제를 그대로 이어받음 | 주소는 누구나 열지만 내용은 각자 시작 |
| 열 수 있는 사람 | 같은 조직에 로그인한 사람 | 누구나 |

내용까지 함께 나누려면 Claude 쪽을, 아무나 열게 하려면 웹 쪽을 쓰면 된다.

## 웹판 쓰는 법

1. 페이지를 연다
2. 우측 상단 **AI 연결**에 본인 Anthropic API 키를 넣는다 (console.anthropic.com 에서 발급)
3. 과목을 만들고 자료를 넣는다

API 키는 **그 브라우저의 localStorage에만** 저장되고 `api.anthropic.com` 외에는
어디로도 전송되지 않는다. 이 저장소에도, 저자에게도 키가 가지 않는다.
다만 브라우저 저장소에 평문으로 들어가니 **공용 컴퓨터에서는 쓰지 마라.**
API 사용료는 키 주인에게 청구된다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 웹에서 여는 완성본. 아래 `artifact.html`을 HTML 문서로 감싼 것 |
| `artifact.html` | Claude 아티팩트로 올리는 원본 조각 (`<html>`/`<head>` 없음 — 아티팩트가 감싼다) |
| `design.html` | 만들기 전에 그린 화면 시안 여덟 장. 왜 이렇게 생겼는지가 적혀 있다 |

`index.html`은 `artifact.html`에서 생성한다. 고칠 때는 `artifact.html`을 고치고 다시 감싼다.

## 기술 메모

- 바닐라 JS. 상태가 바뀌면 화면을 통째로 다시 그린다
- PDF는 pdf.js를 cdnjs에서 필요할 때만 불러와 텍스트를 뽑는다. 글자가 없는 스캔본이면
  페이지를 canvas로 렌더해 이미지로 읽는다
- 정리 결과가 길이 제한에 걸려 잘려도, 온전히 닫힌 단원만 골라내 저장한다
- 실패하면 오류 코드와 실제로 받은 답을 그대로 보여준다 (홈의 **상태** 버튼)

## 한계

- 단답 채점은 문자열 비교라 표기가 다르면 틀린 걸로 나온다. "이거 맞은 걸로" 버튼으로 정정할 수 있다
- 정리본 PDF 내려받기는 아직 없다
- 공유는 앱 단위다. 과목별로 따로 공유할 수 없다
- 웹판은 여러 사람이 내용을 함께 보는 기능이 없다
